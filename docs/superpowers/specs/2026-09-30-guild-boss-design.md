# 길드 보스 — 설계

길드원이 한 주 동안 함께 깎는 **공용 체력** 보스. 길드 전용 보스방(방당 최대 6명)에서 실시간으로 싸우고, 방마다 넣은
피해가 길드의 주간 기록에 합쳐진다. 보스는 바닥에 **예고 공격**을 그리고, 플레이어는 그걸 보고 피한다.
선행: [길드](2026-09-30-guild-design.md), [우편](2026-09-30-mail-design.md), [장비 거래 속성](2026-09-30-tradable-items-design.md).

## 1. 예고 공격 (먼저 만들고, 버섯왕의 내리찍기도 옮긴다)

`src/game/world/telegraphs.ts` (서버와 화면이 같이 씀)

```ts
type Shape =
  | { kind: "circle"; x; z; r }
  | { kind: "ring"; x; z; inner; outer }          // 도넛: 가운데만 안전
  | { kind: "cone"; x; z; yaw; r; arc }            // 부채꼴 (arc: 전체 각도)
  | { kind: "line"; x; z; yaw; length; width };    // 직선: (x, z)에서 yaw 방향으로
interface Telegraph { id; shape; startAt; hitAt; share /* 최대 체력의 몫 */; pool?: { until; tickShare } }
inShape(shape, x, z, grace = EDGE_GRACE /* 0.3m */): boolean   // 가장자리 grace만큼 봐줌
```

- 방 상태 `telegraphs`에 보관. 매 틱 `hitAt`이 지난 것은 그 순간 각 플레이어의 마지막 위치로 판정하고 지운다(장판은
  `pool.until`까지 남아 1초마다 `tickShare`).
- 피해는 **최대 체력의 몫**(레벨과 무관하게 공정): 장비의 받는 피해 감소는 적용, **막기는 적용 안 됨**(피해야만 함).
- 버섯왕 내리찍기: 지금의 링(`slamming`) 대신 보스 둘레 원 예고(반지름 7, 1.5초). 피해는 지금처럼 고정 140(막기 적용
  안 됨으로 바뀜).
- 화면(`src/game/render/telegraphs.ts`): 모양별 바닥 메시. 반투명 빨강, 명중 시각까지 가장자리→안쪽으로 차오름.
  장판은 어두운 보라. 나타날 때 짧은 경고음, 명중 때 충격파.

## 2. 보스와 패턴 (`src/game/world/guildBoss.ts`)

- 주(월요일 0시, 한국 시간; 숲 정화와 같은 주)마다 **고대 드래곤 → 설산 예티 → 장로 글럽** 순서. 탈것 모델을 크게,
  어둡게 칠해서 쓴다(`mnt_dragon`, `mnt_yeti`, `mnt_glub_evolved`). 몬스터 종류 `guild_dragon`·`guild_yeti`·`guild_glub`,
  글럽의 잡몹 `glub_brood`(`mnt_glub`, 작게).
- 기본 물기(고정 피해 45; 잡몹 20) + 패턴 셋을 돌아가며, 같은 것은 연달아 쓰지 않는다. 패턴 사이 4~6초.

| 보스 | 패턴 1 | 패턴 2 | 패턴 3 |
|---|---|---|---|
| 드래곤 | 불기둥: 모든 플레이어 발밑에 원(r 2.5, 1.6초, 40%) | 브레스: 가장 가까운 플레이어 쪽 부채꼴(r 10, 90°, 2초, 55%) | 날개 치기: 보스 둘레 원(r 6, 1.5초, 45%) |
| 예티 | 돌진: 가장 먼 플레이어 쪽 직선(길이 14, 폭 3, 1.5초, 50%) 뒤 끝까지 돌진 | 얼음 비: 무작위 원 7개(r 2, 1.8초, 40%) | 포효: 도넛(안 r 3, 밖 r 10, 2초, 45%) |
| 글럽 | 소환: `glub_brood` 4마리 | 독 웅덩이: 플레이어 근처 원 3개(r 2.5, 1.6초, 30%) 뒤 5초 장판(초당 8%) | 삼키기: 보스 둘레 원(r 5, 1.4초, 60%) |

- 광폭(남은 체력 25% 아래): 예고 시간 ×0.8, 원 개수 +2, 패턴 사이 ×0.7.

## 3. 주간 기록 (`guildBoss` 컬렉션, 길드×주 한 행, `gboss:<길드id>` 잠금)

```ts
{ guild, week, boss, max, damage, stagesPaid /* 0~4 */,
  entries: { [characterId]: "YYYY-MM-DD" /* 마지막 입장한 날 */ },
  hitters: { [characterId]: { account, name, damage } } }
```

- 행은 그 주 첫 입장 때 생긴다. `max = HP_PER_MEMBER(120,000) × max(5, 그때 길드원 수)`.
  (Lv20 전사 초당 약 250 피해 × 하루 3분 × 주 5일 × 효율 0.6 ≈ 13.5만.)
- 단계: 25 / 50 / 75 / 100%. `damage`가 새 단계를 넘길 때마다, 그 주 **입장한 적 있는** 캐릭터 전원에게 우편
  (`guild_boss`, `params: { boss, stage }`):
  - 1단계 2,000골드 + 강화석 5 · 2단계 3,000 + 8 · 3단계 4,000 + 12 (강화석은 거래 불가)
  - 4단계(처치) 6,000골드 + 강화석 20 + **거래 가능 장비 1점**: 기여 1~3위 `weapon_5`/`armor_5` 중 하나, 나머지는
    `weapon_3`/`armor_3`/`weapon_4`/`armor_4` 중 하나.
- 기여도: 캐릭터별 누적 피해. 순위 10위까지 보여 준다.

## 4. 보스방

- 새 구역 `arena`: 원형에 가까운 투기장(가장자리 숲), 포털 없음, 보스는 가운데, 입장 지점은 남쪽.
- 방 이름 `gboss-<길드id>-<1~5>`: 월드가 아니라 길드에 묶여 있어 서버·채널이 달라도 같은 방에 모인다. 방당 최대 6명.
- 입장(`enterArena(n)`, 길드 패널에서, 월드 어디서든): 길드원, Lv10 이상, 오늘(한국 날짜) 아직 입장 안 함, 이번 주 보스가
  살아 있음, 방에 자리가 있음. 입장하는 순간 오늘 입장으로 기록하고 계정 상태에 `arena: { roomId, until: 지금+3분 }`.
- 방 안: 체력은 가득 찬 채로 시작, 부활 없음, 탈것·채널 이동·포털 없음, 쓰러져도 경험치를 잃지 않는다.
  `until`이 지나면 공격·스킬을 받지 않는다.
- 끝(3분이 지나거나 쓰러짐): 화면이 결과(이번 입장 피해, 주간 순위)를 보여 주고 `leaveArena()` → 들어오기 전 채널의
  자리로 돌아간다(보스방에서는 자리를 저장하지 않는다).
- 서버 코드: 지금은 공격·스킬·물약·이동·도착이 "채널 방"만 받는다. 이를 `readPlace(roomId)`
  (`channel` | `arena`)로 넓힌다. 상점·포털·채널·부활은 채널 방에서만.

## 5. 체력 동기화

- 방의 보스 몬스터는 **공용 남은 체력**을 hp로 가진다(최대치는 방 상태 `arena.max`).
- 방 안의 피해는 방 상태 `arenaPending: { total, by: { characterId: { account, name, damage } } }`에 모았다가, 5초마다(방
  틱) 길드 잠금 안에서 주간 기록에 더하고, 남은 체력을 다시 방에 쓴다. 단계 보상은 이때 판정.
- 남은 체력이 0이 되면 모든 방의 보스가 다음 동기화 때 쓰러진다. 그 주에는 더 입장할 수 없다.

## 6. 화면

- 길드 패널 `보스` 탭: 이번 주 보스(이름·그림), 공용 체력 게이지와 단계 표시, 남은 기간, 오늘 입장 여부, 열린 방(1~5)의
  인원과 입장 버튼, 기여도 순위 10위.
- 보스방 HUD: 위쪽 가운데 공용 체력바(단계 눈금), 남은 시간(3:00부터), 나가기 버튼. 끝나면 결과 창.
- 새 주가 시작돼 오늘 입장 안 한 길드원에게는 길드 메뉴에 빨간 점(`guildBadge`에 `bossReady`).
- 문구 5개 언어.

## 7. 테스트

- `telegraphs.ts`: 모양별 안/밖, 가장자리 봐주기 경계, 도넛 안쪽 안전.
- `guildBoss.ts`: 주·보스 순서, 체력 산정(최소 5명), 단계 판정, 순위별 장비 보상, 광폭 배율, 패턴이 연달아 같지 않음.
- 서버: 하루 1회, 방 6명 제한, Lv10 미만·길드원 아님·다른 길드 방 거부, 3분 뒤 공격 거부, 두 방의 피해가 합쳐짐,
  단계 우편이 입장한 캐릭터에게만 한 번씩, 처치 후 입장 거부, 예고 공격이 영역 밖 플레이어를 맞히지 않음, 보스방에서
  쓰러져도 경험치 그대로.
