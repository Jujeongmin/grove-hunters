# 장비 개체와 거래 속성 — 설계

거래소의 선행 작업. 지금은 가방이 아이템 종류별 개수만 세고, 강화 수치(`plus`)가 캐릭터의 "종류별" 값이다. 강화된
장비를 그대로 사고팔려면 장비 한 점이 자기 강화 수치와 거래 가능 여부를 가져야 한다.

## 1. 모델 (`src/game/account/items.ts`)

```ts
export interface GearPiece { uid: string; id: ItemId /* weapon_* | armor_* */; plus: number; trade: boolean }
export interface Gear { weapon: GearPiece | null; armor: GearPiece | null }   // 입은 것
// Character: bag(물약·재료, 거래 불가 개수), bagTrade(재료, 거래 가능 개수), pieces(가방의 장비), gear(입은 장비)
export const MAX_PIECES = 50;   // 가방의 장비(입은 것 제외)
```

- `bag`은 물약과 재료만 센다(장비 종류는 더 이상 들어가지 않는다). 재료는 `bag`(거래 불가)과 `bagTrade`(거래 가능) 두 줄,
  줄마다 최대 99개. 물약은 거래 속성이 없다.
- `Plus` 타입과 캐릭터의 `plus`는 없어진다. 강화 수치는 `GearPiece.plus`.
- `gearStats(gear)`와 `fightStats`·`combatPower`는 입은 조각의 `plus`를 쓴다.
- uid: 서버가 만드는 `g-<10자>`. 변환으로 생긴 조각은 `m-<캐릭터 id>-<종류>-<순번>`(읽을 때마다 같게).

## 2. 얻는 경로와 거래 속성

| 경로 | 장비 | 재료 |
|---|---|---|
| 몬스터 드롭 | `TRADE_DROP_CHANCE = 0.3` | 거래 가능 |
| 대장간 제작 | `TRADE_CRAFT_CHANCE = 0.1` | — |
| NPC 상점 구매 | 불가 | — (상점은 재료를 팔지 않음) |
| 퀘스트·일일 퀘스트·튜토리얼·숲 정화·운영 우편 | 불가 | 불가 |
| 거래소 구매 | 가능(계속 거래 가능) | 가능 |

- 강화해도 거래 속성은 그대로. 부서지면 그 조각이 사라진다.
- 재료를 쓸 때(제작·강화·기부)는 **거래 불가 줄부터** 쓴다.
- NPC 상점에 팔기: 장비는 uid로 한 점, 재료는 줄(거래 가능/불가)을 골라 판다. 판매가는 지금과 같다.

## 3. 기존 세이브 변환 (읽을 때, `readCharacters`)

- 옛 `bag`의 장비 개수 → 그 수만큼 거래 불가 조각. 옛 `gear`(종류 id) → 거래 불가 조각 하나를 입힘.
- 옛 `plus[종류]`는 **한 조각에만**: 그 종류를 입고 있으면 입은 조각, 아니면 가방의 첫 조각. 같은 종류의 나머지는 +0
  (강화 수치가 복제되지 않게).
- 옛 재료는 모두 `bag`(거래 불가)에 남는다. 출처를 알 수 없어서.
- 변환은 읽기에서만 하고, 다음에 무언가 저장될 때 새 꼴로 쓰인다(지금의 캐릭터 변환과 같은 방식). 저장 꼴에 `v: 2`.

## 4. 서버 변경

- `payHunter`: 드롭 장비는 조각으로(30% 거래 가능), 재료는 `bagTrade`로. 조각 칸이 가득 차면 그 드롭은 잃는다(지금 99개
  넘친 드롭과 같다).
- `buyItem`(장비는 거래 불가 조각), `sellItem(id | uid, count, trade?)`, `equipItem(uid)`, `unequipItem(slot)`,
  `enhanceGear(slot)`(입은 조각의 plus), `craftItem`(장비 결과는 10% 거래 가능), `claimQuest`·`claimDaily`·튜토리얼·숲 정화
  보상(거래 불가), `donate`(재료는 거래 불가 줄부터).
- `bagView`: `{ bag, bagTrade, pieces, gear, … }`. `plus` 제거.
- 랭킹 상세(`getRankDetail`)와 방에 보이는 모습(`zoneLook`)은 입은 조각의 종류·plus를 쓴다.

## 5. 화면

- 가방: 장비 조각을 한 칸씩(아이콘, `+N`, `거래 가능`/`거래 불가` 표시). 재료는 두 줄이 따로 보인다(거래 가능 줄에 표시).
- 아이템 설명 창에 거래 가능 여부 한 줄.
- 대장간: 입은 조각의 plus로 강화, 제작 결과에 "10% 확률로 거래 가능" 안내.
- 문구 5개 언어.

## 6. 테스트

- 변환: 옛 가방·장비·plus → 조각. plus가 한 조각에만 붙음, 거래 불가, 두 번 읽어도 같은 uid.
- 장착·해제·판매·강화·부서짐이 조각 단위로 맞음, `MAX_PIECES` 경계.
- 재료 소비가 거래 불가 줄부터.
- 드롭·제작의 거래 가능 확률(난수 주입).
- 서버: 상점 구매 장비는 거래 불가, 기존 테스트 전부 새 꼴로.
