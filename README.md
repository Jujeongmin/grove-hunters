# Grove Hunters (초록숲 사냥꾼)

숲을 무대로 한 웹 MMORPG. 마을에서 시작해 숲 필드 1(무료), 숲 필드 2, 버섯왕의 공터(정식판), 설산(Lv40~60)으로 나아가며
몬스터를 사냥해 레벨을 올린다. 직업 6개, 서버마다 캐릭터 여러 개, 서버마다 채널 10개(채널당 10명). Verse8 배포 대상,
Vite + React + TypeScript + Three.js. (Verse8 GitLab 저장소 이름 `traitor-hunt`는 예전 작업명으로, 배포 연결 때문에 그대로 둔다.)

## 현재 상태

오픈월드 RPG로의 전환(P6)이 끝났다. 처음의 배신자·빙의·투표 매치는 모두 지웠다.

- **들어가기**: 서버 고르기 → 캐릭터 고르기(서버마다 최대 4개, 만들 때 직업 6종과 외형을 정하면 바꿀 수 없다; 이름을 그대로 입력하면 영구 삭제) →
  마지막으로 있던 구역으로 입장.
- **세계**: 초록숲 마을 · 숲 필드 1 · 숲 필드 2 · 깊은 숲 · 버섯왕의 공터, 깊은 숲 동쪽 너머의 설산 전초기지 · 설산 기슭 ·
  얼음 협곡 · 만년설 봉우리 · 빙하의 제단(보스 빙하의 황제). 구역 가장자리의 포털로 오간다.
  서버마다 채널 10개가 있고(메이플스토리처럼 채널 하나가 세계 전체 한 벌), 채널당 모든 구역 합쳐 10명. 포털을 타도 채널은 그대로이고, 채널 목록(C)에서 인원과 친구 위치를 보고 옮길 수 있다. 들어올 때는 지난번 채널, 없으면 친구 채널로 먼저 간다. 구역 하나는 Verse8 방 하나. 마을에는 집과 상인·촌장이 있고, 먼 언덕에는 성이 서 있다.
- **성장**: 사냥·퀘스트로 경험치, 레벨 10에 전직(직업마다 두 갈래). 스킬 1은 직업 것, 스킬 2·3·4는 고른 전직 갈래 것(2는 전직 즉시, 3은 Lv20, 4는 Lv40), 각자 재사용 대기시간.
- **물건**: 몬스터 드롭과 골드, 가방, 장비가 능력치를 바꾼다. 마을 상점, 대장간에서 +1~+10 강화와 재료 제작.
  장비는 한 점씩 따로(강화 수치도 한 점마다), 거래 가능 여부가 붙는다: 드롭 장비 30%, 제작 장비 10%, 상점·퀘스트 장비는 불가.
  드롭 재료는 거래 가능, 쓸 때는 거래 불가 재료부터.
- **거래소**: 모든 서버 공용. 거래 가능 장비(한 점, 강화 수치 그대로)와 재료를 보석으로 사고판다. 재료는 개당 가격으로 올리고
  사는 사람이 원하는 개수만큼 가져가며 남은 개수는 매물로 남는다(장비 10보석·재료 개당 1보석부터, 개수와 가격은 화살표로 조절,
  수수료는 거래마다 5% 내림, 계정당 10개·48시간). 대금과 산 물건, 돌아온 매물은 우편으로.
- **우편**: 계정마다 우편함 하나(시스템 우편만: 운영 선물, 거래소). 30일 보관, 받는 캐릭터의 가방으로.
- **할 일**: 새 캐릭터는 촌장에게 첫 기술과 물약을 받고 스킬 등록·자동 사용·자동 전투를 해 보는 튜토리얼, 촌장이 주는 퀘스트 줄기와 필드마다의 일일 퀘스트, 퀘스트 추적기(누르면 포탈을 넘어서라도 목표나 촌장까지 걸어가고 남은 거리를 보여 줌)와 완료 패널.
- **함께**: 채널 채팅(머리 위 말풍선), 친구(접속 중인 친구의 서버·채널·구역 표시), 채널 이동, 전투력과 레벨 기준 랭킹, 캐릭터 시트.
  길드(모든 서버 공용, 캐릭터 단위, 최대 30명, 길드장·부길드장 3명·길드원, 창설 10,000골드, 탈퇴·추방 뒤 24시간 대기),
  길드원 위치, 머리 위 <길드명>, 채팅창의 길드 탭.
- **소식**: 업데이트 소식판. 안 읽은 소식이 있으면 들어올 때 한 번 뜨고, 메뉴에서 언제든 본다(`src/game/news.ts`에 맨 앞에 추가).
- **지도**: 화면 구석의 미니맵과 N으로 여는 구역 전체 지도. 땅과 숲은 게임이 밟고 다니는 사진 그대로, 출입구는
  포털의 마법진, 마을 사람은 각자의 아이콘. 큰 지도에서 한 곳을 누르면 그리로 걸어간다.
- **숲 정화·마을 복구**: 서버마다 한 주 동안 모두의 처치로 숲을 정화한다(3,000마리, 30/60/100% 단계 보상, 100%면
  숲 필드 1에 정화의 수호자). 60%마다 마을 건물 터가 열리고, 촌장에게 재료와 골드를 기부해 약초상·훈련소·여관·망루를
  영구히 짓는다. 건물마다 서버 전체 혜택(물약 할인, 경험치, 쓰러질 때 손실 절반, 미니맵 보스 표시)과 상위 기부자 이름.
- **편의**: 자동 전투와 자동 물약, 절전 화면과 화면 켜짐 유지, 접히는 메뉴 버튼, 마우스나 손가락만으로 되는 조작, 설정 패널.
- **결제(500 VX)**: 무료로 마을·숲 필드 1·레벨 10까지. 구매하면 숲 필드 2, 깊은 숲, 보스 구역과 레벨 제한이 열린다.

조작: 마우스만으로 전부 된다. 왼쪽 아래 가상 패드나 WASD(방향키)로 이동, 화면을 끌어 시점(마우스는 잠그지 않는다), 클릭이나
공격 버튼으로 공격, 오른쪽 버튼 막기. 키보드 단축키: Space 점프, 1~4 스킬, Q 물약, E 대화, J 퀘스트 수행, Enter 채팅,
M 메뉴 접기·펴기, N 지도, I 가방, K 스킬, L 퀘스트, O 랭킹, U 대장간, Z 길드, X 거래소, F 우편, Y 소식, B 절전, P 설정,
Escape 열린 것 닫기.

플레이어와 NPC는 모듈형 영웅 모델의 파츠 조합이고, 숲·마을·소품은 Unity 무료 에셋을 변환한 모델이다.

## 3D 모델은 이 저장소에 없다

게임이 쓰는 모델은 Unity Asset Store 무료 에셋을 변환한 것이고, 에셋 약관이 에셋 파일을 따로 배포하는 것을 금지한다.
그래서 `public/assets/models/*.glb`는 저장소에서 제외되어 있고 목록(`manifest.json`)만 있다. 모델을 만들려면:

1. Unity Asset Store에서 [에셋 목록](docs/licenses/asset-provenance.md)의 에셋을 직접 받아 Unity 프로젝트(`../My project`)에 가져온다.
2. Unity 에디터에서 그 프로젝트를 닫고 `npm run export-glb` (Unity 6000.5.2f1 필요, 결과는 `art-src/_glb`).
3. `npm run models` (결과는 `public/assets/models`).
4. `node scripts/extract-ui.mjs` (UI 조각과 아이콘, 결과는 `public/assets/ui`, 저장소에서 제외).
